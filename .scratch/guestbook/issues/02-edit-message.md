# 02: 메시지 수정

**What to build:** 글쓴이가 자기 방명록 글의 [수정]을 누르면 그 자리에서 현재 메시지가 채워진 편집창과 비밀번호 입력창이 펼쳐진다. 맞는 비밀번호로 저장하면 메시지가 바뀌어 목록에 바로 반영되고 "(수정됨)"이 표시되며, 목록 순서는 바뀌지 않는다. 비밀번호가 틀리면 "비밀번호가 일치하지 않습니다", 방명록 글이 이미 없으면 "이미 삭제된 방명록 글입니다"가 그 방명록 글 옆에 표시되고, 편집 중이던 메시지는 남아 있다. 자세한 결정은 [spec](../spec.md) 참고.

**Blocked by:** 01 (방명록 글 작성과 목록 조회)

**Status:** done

- [x] 방명록 모듈에 메시지 수정(id, 비밀번호, 새 메시지) 동작이 추가된다. 결과는 성공 | 입력 오류 | 비밀번호 불일치 | 이미 삭제된 방명록 글 중 하나다
- [x] 판정 순서는 방명록 글 존재 → 비밀번호 일치 → 새 메시지 검증(작성과 같은 규칙)이다. 비밀번호 비교는 상수 시간이다
- [x] 성공하면 메시지와 수정 시각만 바뀌고, 이름·비밀번호·작성 시각은 그대로다
- [x] 수정 시각이 있는 방명록 글에는 목록에서 "(수정됨)"이 표시되고, 정렬은 계속 작성 시각 기준이다
- [x] 편집은 목록 안에서 그 자리에 펼쳐지며(모달·별도 페이지 없음), 취소하면 원래 상태로 돌아간다
- [x] 실패 안내는 해당 방명록 글 근처에 표시되고 입력값이 유지된다
- [x] Vitest 테스트: 맞는 비밀번호로 수정 성공, 틀린 비밀번호는 거부되고 메시지 불변, 없는 id는 이미 삭제된 방명록 글, 새 메시지 입력 오류, 수정 후에도 순서 불변, 이름이 같고 비밀번호가 다른 두 방명록 글이 서로 수정 불가
- [x] `npm test`, `npm run lint`, `npm run build`가 통과한다
