# 03: 방명록 글 삭제

**What to build:** 글쓴이가 자기 방명록 글의 [삭제]를 누르면 그 자리에서 비밀번호 입력창이 펼쳐진다. 맞는 비밀번호를 넣으면 재확인 없이 방명록 글이 영구 삭제되어 목록에서 바로 사라진다. 비밀번호가 틀리면 "비밀번호가 일치하지 않습니다", 방명록 글이 이미 없으면 "이미 삭제된 방명록 글입니다"가 그 방명록 글 옆에 표시된다. 자세한 결정은 [spec](../spec.md) 참고.

**Blocked by:** 01 (방명록 글 작성과 목록 조회)

**Status:** ready-for-agent

- [ ] 방명록 모듈에 방명록 글 삭제(id, 비밀번호) 동작이 추가된다. 결과는 성공 | 비밀번호 불일치 | 이미 삭제된 방명록 글 중 하나다
- [ ] 판정 순서는 방명록 글 존재 → 비밀번호 일치이며, 비밀번호 비교는 상수 시간이다
- [ ] 삭제는 하드 삭제이며, 맞는 비밀번호면 "정말 삭제할까요?" 같은 추가 확인 없이 바로 지운다
- [ ] 비밀번호 입력창은 목록 안에서 그 자리에 펼쳐지고(모달·별도 페이지 없음), 취소할 수 있다
- [ ] 실패 안내는 해당 방명록 글 근처에 표시된다
- [ ] Vitest 테스트: 맞는 비밀번호로 삭제하면 목록에서 사라짐, 틀린 비밀번호는 거부되고 방명록 글 유지, 삭제 후 다시 삭제하면 이미 삭제된 방명록 글, 이름이 같고 비밀번호가 다른 두 방명록 글이 서로 삭제 불가
- [ ] `npm test`, `npm run lint`, `npm run build`가 통과한다
